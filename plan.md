# План разработки сайта веб-студии нового поколения: «Swiss Precision & Electric Blue»

> **Файл:** `plan.md`  
> **Основа проекта:** `structure.md` (структура и копирайтинг 14 блоков) + `design copy.md` (швейцарская дизайн-система B2B)  
> **География и рынок:** Казахстан (Алматы, Астана, Шымкент и все регионы) / СНГ  
> **Позиционирование:** Технологичная студия веб-разработки с внедрением AI, высокой скоростью (PageSpeed 95+), прозрачной сметой, официальным договором и бесплатным концептом до предоплаты.

---

## 1. Сквозные (глобальные) скилы проекта

Перед началом поэтапной верстки отдельных блоков фиксируются базовые скилы, действующие на весь проект:

| Глобальный скил | Роль и область применения |
| :--- | :--- |
| **`high-end-visual-design`** | Строгая реализация швейцарской дизайн-системы (архитектурная 8pt-сетка, благородные тени без грязи, микро-отступы, контрастная типографика, устранение шаблонных паттернов «дешевого ИИ-дизайна»). |
| **`full-output-enforcement`** | Принцип 100% цельного кода. Полный запрет на сокращения, заглушки вида `// ... здесь код` и плейсхолдеры. Все файлы пишутся от первого до последнего символа в законченном виде. |
| **`design-taste-frontend`** | Чистая семантическая верстка, выверенные интерактивные состояния кнопок и карточек, отсутствие визуального шума. |
| **`core-web-vitals`** | Оптимизация скорости загрузки (LCP < 1.2s, CLS = 0, FID/INP идеальны), инлайн критического CSS, оптимизация векторной графики, моментальный рендеринг. |
| **`mobile-friendly`** | Адаптивность «Mobile-First / Fluid Grid»: идеальный отклик на экранах от 320px до 4K, высота тач-таргетов от 48px, плавная прокрутка, поддержка свайпов. |
| **`eeat-signals`** | Размещение реквизитов (ИП/ТОО, БИН/ИИН), официального договора, гарантийных обязательств на 12 месяцев, прозрачных схем оплаты 50/50. |
| **`humanizer`** | Проверка всех текстов и микрокопии на естественность, убедительность и деловой тон без шаблонных штампов и водянистых лозунгов. |
| **`schema-markup`** | Внедрение микроразметки JSON-LD (`Organization`, `WebSite`, `FAQPage`, `OfferCatalog`, `LocalBusiness`). |
| **`page-metadata`**, **`open-graph`**, **`twitter-cards`** | Полный комплект метатегов для поисковиков, предпросмотра в WhatsApp, Telegram, Facebook и LinkedIn. |

## 2. Архитектура и стек технологий

- **HTML5:** Семантическая разметка (`<header>`, `<main>`, `<section>`, `<article>`, `<footer>`, `<dialog>`).
- **CSS3 (Vanilla Modern CSS):**
  - Подключение Google Fonts (`Manrope`, `Inter`, `Space Grotesk`).
  - Файл дизайн-системы `design-system.css` с переменными (`--color-*`, `--radius-*`, `--shadow-*`, `--space-*`, `--ease-out`).
  - Flexbox и CSS Grid для сложных сеток.
- **JavaScript (Vanilla Modern ES6+):**
  - Модульный, легковесный, без тяжелых библиотек (чистая производительность).
  - Интерактивный квиз с переключением шагов и расчетом скидки.
  - Живое превью макетов портфолио с колесиком прокрутки внутри каркаса ультрабука.
  - Маска ввода телефонного номера формата Казахстана (`+7 (7XX) XXX-XX-XX`).
  - Аккордеон FAQ с плавной CSS-анимацией (`grid-template-rows`).
  - Exit-Intent всплывающее окно при попытке покинуть вкладку (с памятью в `localStorage`).
  - Плавающий виджет связи в WhatsApp.

## 3. Детальный план реализации по блокам со спецификацией скилов

### Блок 1: Header (Фиксированная навигационная панель)
- **Цель:** Навигация, формирование статуса надежной компании, быстрый вход в диалог в один клик.
- **Состав:** Логотип со слоганом, десктоп-меню (6 ссылок с плавным скроллом), бейдж статуса (пульсирующая точка «Принимаем заявки онлайн»), прямой телефон `+7 (7XX) XXX-XX-XX`, кнопка «Обсудить проект» (WhatsApp CTA), мобильное бургер-меню.
- **Используемые скилы:**
  - `navigation-menu-generator` — архитектура прилипающей шапки с эффектом Glassmorphism (`backdrop-filter: blur(12px)`), доступная мобильная навигация.
  - `logo-generator` — векторная компоновка логотипа в SVG, типографика названия студии.
  - `cta-generator` — кнопка быстрого перехода в диалог с тактильным эффектом нажатия `scale(0.98)`.
  - `high-end-visual-design` — аккуратные микро-отступы, тонкий контур границы `1px solid var(--color-border-subtle)`.

### Блок 2: Hero-экран (Первый экран с главным оффером)
- **Цель:** Захват внимания за 3 секунды, снятие страха предоплаты, сбор телефона на бесплатный эскиз.
- **Состав:** Сплит 60/40. Слева: бейдж `🚀 Запуск от 5 дней по Казахстану`, заголовок H1 (Manrope 800) «Создаем умные сайты с AI-интеграцией, которые окупаются с первого месяца», подзаголовок, инлайн-форма ввода телефона с маской `+7...` и кнопкой «Получить концепт бесплатно →», 3 микро-буллета доверия (PageSpeed 95+, Оплата 50/50, Домен и SSL в подарок). Справа: интерактивный 3D-макет ультрабука с плавающими карточками метрик конверсии и Kaspi Pay.
- **Используемые скилы:**
  - `hero-generator` — композиция сплит-экрана, визуальная иерархия, отступы и расположение над сгибом экрана.
  - `copywriting` — отточенный конверсионный текст по формуле выгоды и снятия возражений.
  - `trust-badges-generator` — карточки-буллеты доверия с иконками скорости, юридической чистоты и подарков.
  - `cta-generator` — инлайн-форма захвата в одну строку с плавным фокусом и синим свечением кнопки.
  - `gpt-taste` — мягкий 3D-наклон (tilt-эффект) при движении курсора над макетом ноутбука.

## 4. Этапы выполнения работ (Action Workflow)

```
Этап 1: Архитектура файлов и подключение дизайн-системы
   ├─ Создание `index.html` с полным набором метатегов и шрифтов Google Fonts
   ├─ Создание `css/design-system.css` со всеми токенами из `design copy.md`
   └─ Создание `css/components.css` с модульными классами UI

Этап 2: Верстка каркаса и первых конверсионных экранов
   ├─ Блок 1: Header (шапка, меню, онлайн-статус, мобильный бургер)
```
